| HUD の DetailPanel: ホバー 0.6 秒でクリック可能になり、コピー・覚える・今後表示しない・詳しく見る（Archive で開く）を表示 | HD-4, PS-1 | M |
| Personalization を仕様の重みに合わせる（閉じる −1 / More +2 / 検索 +3 を内部スケールに換算） | PS-1 | S |

| 既知用語: 「今後表示しない」と、3 回以上表示した用語は再表示しない | EX-3, P-5 | S |

| Pause Until Tomorrow | PV-4 | S |

**完了条件**
- 既存の Visual Memory が SQLite に移行され、検索結果が v0.4 と同等以上。
- 技術記事を読むと、知らない専門用語（例: RAG）に 1 行解説が出る。一般的な語（API・URL 等）には出ない。
- HUD からコピー・今後表示しないが操作でき、操作しないときは下のアプリのクリックを妨げない。
- Apple Intelligence が無い環境でも、M1 の他の機能は劣化せずに動く。

### M4 — クラウドと Web（v0.8、オプトイン）※ v0.11 で方針変更

> D-7 により、M4 のクラウド部分（`NetworkGate`・`CloudAIProvider`・Gemini）は v0.11 で削除した。識別の方針（確度による表示制御・キャッシュ・WEB / WIKI ボタン）は M6 で端末内の推定に引き継いでいる。以下は当時の計画として残す。

**前提となる判断**: D-2（クラウドの提供元）、D-3（著名人推定の可否）、D-4（ネットワーク Entitlement）。

| タスク | 要件 | 規模 |
| --- | --- | --- |
| `NetworkGate`: 通信を 1 か所に集約。オプトインするまで一切通信しない。送信前に秘密情報検出を必ず通す | PD-7 | M |
| `SearchProvider`: まず Wikipedia REST API（キー不要）。結果を `knowledge` に 30 日キャッシュ | 仕様 §28–29 | M |
| `CloudAIProvider`: 切り抜き画像＋文脈を送り、構造化結果を受け取る。API キーは Keychain | 仕様 §27 | L |
| 動植物の識別（和名・学名・分類・生息地）。確信度が低ければ「〜の可能性があります」 | ID-1, ID-2 | M |
| ランドマークの識別 | ID-3 | M |
| 著名人の推定（D-3 が「実施」の場合のみ）: 公人のみ、顔データは保存しない、低確信度は表示しない | ID-4 | L |
| HUD の More に「Web 検索」「Wikipedia」を追加 | HD-4 | S |
| Battery モードではクラウドを使わない | NF-5 | S |

**完了条件**
- オプトイン前に通信が一切発生しないことを、ネットワーク監視で確認し記録する。
- 同じエンティティの 2 回目以降は通信せずにキャッシュから表示する。
- 送信内容のプレビュー（何を送ったか）を設定画面で確認できる。

## 5. 実機検証チェックリスト（M0 で実施、以後各リリースで再実施）

**起動・権限**
- [ ] 初回起動でガイド（FIELD MANUAL）が開き、画面収録を許可するまで Start が押せない
- [ ] ガイドから画面収録を許可して再起動すると、Start 後に `Running` になる（2 回目以降はガイドが出ない）
- [ ] メニューの Welcome Guide… でガイドを開き直しても、一時停止は解除されない
- [ ] Team を設定して再ビルドしても権限が保持される

**翻訳と HUD**
- [ ] フランス語のニュース記事を開くと 1〜3 秒で HUD が出る
- [ ] HUD が対象テキストの近くに出て、文字を隠さない
- [ ] レティクル・引き出し線・解読演出が描画され、カクつかない
- [ ] 同じ文章は 5 分間再表示されない
- [ ] OK / Cancel / メニュー項目などには反応しない
- [ ] YouTube の動画再生中に HUD が出続けない（字幕は止まった時点で 1 回まで）
- [ ] HUD の下のボタンがクリックできる（クリック透過）
- [ ] ホバー中は HUD が消えない
- [ ] 翻訳モデル未インストールの言語では何も出ない
- [ ] macOS 15 と macOS 26 の両方で翻訳が出る（macOS 15 はブリッジ方式）

**Pause とプライバシー**
- [ ] Pause 5 分で止まり、5 分後に自動で再開する
- [ ] 1Password など除外アプリを前面にすると解析が止まる（デバッグ表示で確認）
- [ ] 除外アプリのウィンドウが HUD の解析対象にならない
- [ ] `~/Library/Containers/…/Data` 以下に画像ファイルが作られていない

**BRIEF と Archive**

- [ ] ⌥⌘K で Archive が開閉する
- [ ] 「昨日のフランス語」で前日の記録が出る
- [ ] Purge で全件が消え、再起動後も残っていない

## 7. 進め方のルール

- マイルストーンごとにブランチを切り、PR で CI（Linux のコアテスト＋macOS 15 / 26 のビルド）が通ってからマージする。
- 新しいロジックはまず `AmbientCore` に純粋関数・値型として書き、ユニットテストを付ける。
- 新しい権限・Entitlement・外部依存の追加は、本書 §4 に判断事項として記録してから行う。
- クラウド LLM・外部 API・ネットワーク通信は使わない（D-7）。必要になったら D-7 の見直しとして判断事項に記録する。
- 各マイルストーンの終わりに §5 のチェックリストを実施し、SPEC.md の状態列を更新する。
- 次のマイルストーンの着手には [IMPLEMENTATION_PROMPT.md](IMPLEMENTATION_PROMPT.md) を使う。
