# Ambient Screen Intelligence かんたんマニュアル（v0.11）

画面をいっしょに見て、役に立ちそうなときだけ小さなカード（HUD）で補足するメニューバーアプリです。翻訳・専門用語・エラーの原因・単位や時差の換算などを、**すべてこの Mac の中で**行います。アプリはインターネットに接続しません。

> 基本は何も表示しません。ふだんは存在を忘れていて大丈夫です。

---

## 1. はじめに

### 1.1 必要なもの

| 項目 | 内容 |
| --- | --- |
| macOS | 15 以降（macOS 26 推奨） |
| Apple Intelligence | なくても使えます。あると「AI」の付いた機能（要約・識別・説明など）が使えます（macOS 26） |
| 翻訳言語 | 翻訳したい言語を「システム設定 › 一般 › 言語と地域 › 翻訳言語」でダウンロード |

### 1.2 最初の起動

1. 起動するとメニューバーに 👁 が出て、ようこそガイド（FIELD MANUAL）が開きます。
2. 「画面へのアクセス」で **画面収録** を許可し、アプリを一度終了して開き直します（macOS の仕様です）。
3. 翻訳先の言語を選び、ガイドの **開始** を押します。メニューが「稼働中」になれば準備完了です。

ガイドはメニューの「ようこそガイド…」でいつでも開き直せます。

## 2. ふだんの使い方

### 2.1 自動で出るカード

| 画面に出たもの | カード |
| --- | --- |
| 外国語の文章 | 翻訳（AI があれば「ひとことメモ」付き） |
| 知らない専門用語・略語 | 意味（AI、または以前に画面で見た定義、macOS の辞書） |
| ターミナル・エディタのエラー | 原因と次の一手、スタックトレースの「自分のコード」の行 |
| QR コード | 行き先の URL |
| 動物・植物・料理・建物などの写真 | 名前の推定（AI） |
| 字幕に出た著名人の名前（顔が写っているとき） | 肩書きと代表作の推定（AI） |
| 配信サイトで見始めた映画・アニメ | 作品カード（AI、有名な作品のみ） |
| ニュース記事 | 背景と、以前に読んだ関連記事 |
| 画面共有中の API キー・パスワード・マイナンバーなど | 警告（値は表示も保存もしません） |
| 4 時間以上あとに戻ってきた | 「前回の続き」 |

カードは数秒で消えます。同じ内容は 5 分間出ません。

### 2.2 カードの見方

- 上の帯: カードの種類（例: `INTERCEPT // LINGUISTIC` は翻訳、`ALERT // FAULT ANALYSIS` はエラー）。
- 下の行 `SRC ▸ …`: 出どころ。
  - `RULE`: 決まったルールによる結果（換算など）
  - `ON-DEVICE ML`: Apple の翻訳・画像認識
  - `ON-DEVICE AI · ESTIMATE`: この Mac の AI による**推定**（外れることがあります）
  - `DICTIONARY`: macOS の辞書
  - `YOUR HISTORY`: 自分の閲覧履歴
- 名前に「（かもしれません）」が付くのは、画面上の文字で確かめられなかった推定です。

### 2.3 カードの操作

カードにポインタを 0.6 秒置くと、消えなくなり、ボタンが出ます（ポインタを置かなければ下のアプリをそのままクリックできます）。

| ボタン | 動作 |
| --- | --- |
| COPY | 内容をコピー |
| ARCHIVE | アーカイブで関連する記録を開く |
| WEB / WIKI | ブラウザで Google 検索・Wikipedia を開く |
| KNOWN | この用語は今後説明しない |
| MUTE 〇〇 | この言語は今後翻訳しない |
| NOT USEFUL | 役に立たなかった（似たカードが出にくくなる） |
| ✕ | 閉じる |

## 3. 自分から調べる

| 操作 | できること |
| --- | --- |
| **ポインタを 2 秒止める** | その場所を優先して読み取ります。「72°F」「5 miles」→ メートル法、「3pm PST」→ 日本時間、`1700000000` → 日時、「10月20日」→「13日後（火）」、`*/5 * * * *` → 「5分ごと」。エディタのコードなら何をしているかを説明（AI） |
| **⌥（Option）を押しながら丸で囲む** | 囲んだところを必ず調べます。QR・エラー・外国語・単位・用語・コード・写真・文章の要点（AI）のうち一番合うものを 1 つ表示。何も分からなければ `NO INTEL` |
| **⌥⌘S**（メニュー「画面を要約」） | 今の画面の文章を 3 行に要約し、アーカイブに残します（AI） |
| **⌥⌘K**（メニュー「アーカイブ…」） | これまでのカードの記録を開きます（§4） |

丸を描くコツ: ⌥ を押したまま、対象のまわりをくるっと 1 周して ⌥ を離します。小さすぎる丸や、ゆっくりすぎる（4 秒以上）丸は無視されます。

## 4. アーカイブ（⌥⌘K）

| タブ | 内容 |
| --- | --- |
| RECORDS | 表示したカードの記録。「昨日のフランス語」「museum yesterday」のように日付・言語・言葉で検索。クリックでコピー |
| SESSIONS | 作業のまとまり（例: 「映画館の時刻表の開発」）と、自動ブックマーク（★） |
| TODAY | 今日の主なテーマと時間 |
| AI LOG | この Mac の AI の回答の記録。表示しなかった回答（DECLINED / FILTERED / FAILED）も含む。検索・コピー・CLEAR AI LOG |

**アーカイブに質問する（AI）**: 検索欄に「昨日読んだ RAG の記事は何？」のように末尾を「?」にして入力し、Return を押すと、自分の記録だけを根拠に答え、使った記録を示します。記録にないことは「記録がない」と答えます。

**PURGE** ですべての記録を消せます。

## 6. 設定

| セクション | 主な項目 |
| --- | --- |
| 翻訳 | 翻訳先の言語、「英語は読めるので翻訳しない」、翻訳しない言語 |
| 解析 | モード（省電力 / 標準 / 高性能）、画像の分類、マウスのあるディスプレイを追う |
| 機能と優先順位 | 機能ごとのオン・オフ。▲▼ で順番を変えると、同時に複数出せるときに上のものが優先されます（丸で囲んだときも同じ）。「順番を元に戻す」 |
| その他の機能 | ひとことメモ、迷うカードの AI 判定、略語、ルールのエラーヒント、辞書、作品カード、ニュースの背景、共有中の警告、丸で囲む、アーカイブへの質問、画面の要約 |
| ビジュアルメモリ | カードの記録、読んだページの記録、ブラウザの URL、前回の続き、AI の回答の記録、保存期間（1 / 7 / 30 日）、アーカイブを消去 |
| HUD | 表示位置（テキストの近く / 右上）、学習した好みをリセット |
| 除外アプリ | 解析しないアプリ（パスワード管理・メッセージ・写真は最初から除外） |
| 映画・アニメ・ニュース | ネタバレの段階（0 なし / 1 見ているところまで / 2 軽め / 3 制限なし） |
| 画面共有 | 共有中に秘密情報を隠す（実験的） |

「AI」の印が付いた機能は Apple Intelligence が必要です。

---

## 7. Apple Intelligence がない Mac でできること

翻訳（翻訳モデルが必要）、画面で定義された略語の展開、辞書の意味（丸で囲んだときなど）、単位・時差・日付・cron の換算、エラーのルールヒントと「自分のコード」の行、QR コード、秘密情報の警告、アーカイブの検索、作業セッション、丸で囲んで調べる（AI を使う答え以外）。

---

## 8. プライバシー

- 画面の画像は保存しません。メモリの中だけで扱います。
- アプリはインターネットに接続しません（ネットワークの権限を持っていません）。WEB / WIKI はブラウザを開くだけです。
- 記録するのは、カードに出した内容、（オンの場合）読んだページのタイトル・URL（クエリなし）・閲覧時間、（オンの場合）AI の回答だけです。この Mac の中に保存され、バックアップの対象外で、いつでも消せます。
- 秘密情報を含む文は、翻訳・説明・記録・AI への入力の対象にしません。
- パスワード管理アプリなどの除外アプリは、画像から取り除かれ解析されません。

## 9. 困ったとき

| 症状 | 確認すること |
| --- | --- |
| 何も出ない | メニューが「稼働中」か。画面収録を許可して再起動したか。そもそも「出さない」のが基本です。⌥ で丸く囲むと確実に反応します |
| 翻訳が出ない | 翻訳言語をダウンロードしたか。「英語は読めるので翻訳しない」や「〇〇 を翻訳しない」になっていないか。設定の「翻訳」がオンか |
| カードが多すぎる | NOT USEFUL を押す。設定の「機能と優先順位」で不要な機能をオフにする。一時停止 |
| AI の機能が使えない | macOS 26 で Apple Intelligence がオンか（設定に「AI」の印のある項目） |
| 推定が間違っている | 「かもしれません」は推定です。NOT USEFUL を押すと出にくくなります。AI LOG で AI が何と答えたか確認できます |
| 丸で囲んでも反応しない | ⌥ だけを押しているか（⌘ や ⇧ を一緒に押さない、マウスボタンを押さない）。1 周以上、4 秒以内に描く |
| ⌥⌘K / ⌥⌘S が効かない | ほかのアプリが同じショートカットを使っていないか |
