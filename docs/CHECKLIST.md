# 実機検証チェックリスト

リリースごとに実施し、結果を `docs/perf/` に記録する（例: [perf/v0.10-device-check.md](perf/v0.10-device-check.md)）。❌ は再現手順を残し、Core のテストに落とせるものは落としてから直す。要件は [SPEC.md](SPEC.md)、計画は [ROADMAP.md](ROADMAP.md)。

## 準備

1. Xcode で Team を設定してビルド（⌘R）。
2. 設定 › 開発者向け › **デバッグ表示** をオン。画面左上に `◢ DEBUG // PIPELINE` が出る（変化領域＝マゼンタ点線、OCR 範囲＝黄、表示した候補＝緑、見送った候補＝赤。認識テキストは出ない）。
3. Console.app でサブシステム `com.onishi.AmbientScreenIntelligence` を表示する。Instruments の Points of Interest に `ocr` / `translate` 区間が出る。
4. 設定 › ビジュアルメモリ › 「AI の回答を記録」をオンにすると、Archive の AI LOG で LLM の応答と時間を確認できる。

## 項目

**起動・権限**
- [ ] 初回起動でガイド（FIELD MANUAL）が開き、画面収録を許可するまで Start が押せない
- [ ] ガイドから画面収録を許可して再起動すると、Start 後に `Running` になる（2 回目以降はガイドが出ない）
- [ ] メニューの Welcome Guide… でガイドを開き直しても、一時停止は解除されない
- [ ] Team を設定して再ビルドしても権限が保持される

**翻訳と HUD**
- [ ] フランス語のニュース記事を開くと 1〜3 秒で HUD が出る
- [ ] HUD が対象テキストの近くに出て、文字を隠さない
- [ ] レティクル・引き出し線・解読演出が描画され、カクつかない
- [ ] 同じ文章は 5 分間再表示されない
- [ ] OK / Cancel / メニュー項目などには反応しない
- [ ] YouTube の動画再生中に HUD が出続けない（字幕は止まった時点で 1 回まで）
- [ ] HUD の下のボタンがクリックできる（クリック透過）
- [ ] ホバー中は HUD が消えない
- [ ] 翻訳モデル未インストールの言語では何も出ない
- [ ] macOS 15 と macOS 26 の両方で翻訳が出る（macOS 15 はブリッジ方式）

**HUD の操作（More）**
- [ ] HUD にポインタを 0.6 秒置くと COPY / ARCHIVE / NOT USEFUL / MUTE / ✕ などが出る。キーボードの入力先は元のアプリのまま
- [ ] COPY・ARCHIVE・NOT USEFUL・MUTE・✕ がそれぞれ効く。ポインタを外すと 0.4 秒で元のクリック透過に戻る
- [ ] カードの下に出典（`SRC ▸ …`）が出て、カードが窮屈にならない

**Pause とプライバシー**
- [ ] Pause 5 分で止まり、5 分後に自動で再開する
- [ ] 1Password など除外アプリを前面にすると解析が止まる（デバッグ表示で確認）
- [ ] 除外アプリのウィンドウが HUD の解析対象にならない
- [ ] `~/Library/Containers/…/Data` 以下に画像ファイルが作られていない

**BRIEF と Archive**
- [ ] macOS 26 + Apple Intelligence で BRIEF が出る。無効な環境では行ごと出ない
- [ ] ⌥⌘K で Archive が開閉する
- [ ] 「昨日のフランス語」で前日の記録が出る
- [ ] Purge で全件が消え、再起動後も残っていない

**マルチディスプレイ**
- [ ] 「ポインタのあるディスプレイを追従」でディスプレイを移動すると 2 秒程度で切り替わる

**ローカライズ・アクセシビリティ（v0.10）**
- [ ] システム言語が日本語のとき、メニュー・設定・ガイドが日本語になる（HUD の演出文字は英語のまま）
- [ ] 英語環境では英語のまま
- [ ] VoiceOver をオンにすると HUD の内容が一度だけ読み上げられる
- [ ] 「視差効果を減らす」で解読演出・スイープが省略される
- [ ] アプリアイコンが Finder・設定ウィンドウ・通知で表示される

**配布（D-6 決定後）**
- [ ] `scripts/release.sh` で公証済み DMG ができ、別の Mac で Gatekeeper の警告なしに起動できる

**ローカル AI（v0.11）**
- [ ] 旧版で Gemini の API キーを保存していた場合、起動後にキーチェーンアクセスから消えている
- [ ] アプリが通信しない（Little Snitch / `nettop` で 0 件。WEB / WIKI はブラウザ側の通信のみ）
- [ ] 設定に「クラウド識別」が無く、「端末内の知識」が表示される。ガイドの 5 番目が「端末内の知識」
- [ ] 動物・植物の写真で、分類が具体的なときだけ `TARGET // IDENTIFICATION` が「〜かもしれません」付きで出る。キャプションに名前があると断定になる
- [ ] 顔と字幕の人名がある動画で、有名人なら `DOSSIER // PUBLIC FIGURE` が出る。一般人や不明なら出ない
- [ ] 有名な映画・アニメで作品カードが出る。知らない作品・一般の動画では出ない
- [ ] ニュース記事で「この話題の背景（端末内の推定）」に最近の出来事を断定する文が出ない
- [ ] 記事で「Retrieval-Augmented Generation (RAG)」を見た後、別のページの「RAG」に展開が出る（Apple Intelligence をオフにした状態）
- [ ] 「72°F」「5 miles」にポインタを 2 秒置くと `INTEL // CONVERSION` が出る。置かなければ出ない
- [ ] Apple Intelligence をオフにして `ModuleNotFoundError` を表示すると、ルールのヒントが出る
- [ ] Foundation Models の識別・作品・ニュースの応答時間（目安 1〜3 秒）と、その間に UI が固まらないこと

**丸で囲んで調べる（v0.11、LA-60）**
- [ ] ⌥ を押しながらポインタで丸を描くと軌跡が描かれ、⌥ を離すと `ACQUIRING` の枠が出て、1〜3 秒でカードが出る
- [ ] 入力監視・アクセシビリティの許可を求められない（`CGEventSource.flagsState` のポーリングで ⌥ が読める）
- [ ] ⌥ を押して文字を打つ（特殊文字の入力）・⌥ を押しながらドラッグ・⌘⌥ のショートカットでは何も起きない
- [ ] 普段のマウス操作（⌥ なし）では軌跡も反応も出ない。⌥ を押したまま直線やジグザグを描いても反応しない
- [ ] 外国語の段落 → 翻訳、エラー行 → 原因、「72°F」→ 換算、QR → URL、略語 → 解説、コード → 要約、写真 → 推定、普通の文章 → 要点（Apple Intelligence あり）
- [ ] 同じものを続けて 2 回囲んでも 2 回とも出る（クールダウンを無視）
- [ ] 何も無い場所を囲むと `NO INTEL` が 1.5 秒だけ出る
- [ ] 除外アプリ（1Password など）の上で囲んでも何も解析しない
- [ ] ⌥ を押している間だけ CPU が少し上がり、離すと元に戻る（60 Hz ポーリング）
- [ ] 複数ディスプレイで、キャプチャ中のディスプレイの外に出ると軌跡が消える

**機能の設定と AI LOG（v0.11）**
- [ ] 旧版で「ひとことメモ」などをオフにしていた場合、更新後も該当の機能がオフのまま
- [ ] 「翻訳」をオフにすると外国語に何も出ない。丸で囲んでも翻訳されず、次の候補（要点など）になる
- [ ] 「翻訳」を「エラーの原因」より上にすると、両方が見える画面で翻訳が出る
- [ ] 設定の ▲▼ と「順番を元に戻す」が効き、再起動後も順番が保たれる
- [ ] Archive の AI LOG に、表示した回答と DECLINED / FILTERED / FAILED の回答が新しい順に出る。検索・クリックでコピー・CLEAR AI LOG が効く
- [ ] 「AI の回答を記録」をオフにすると新しい行が増えない。PURGE で AI LOG も消える

**換算・出典・質問（v0.11）**
- [ ] 「3pm PST」「15:00 UTC」「1700000000」「2026-10-20」「10月20日」にポインタを 2 秒置くと、手元の時刻・日時・「13日後（火）」が出る。夏時間の地域名（PT / ET）も正しい
- [ ] カードの下に出典（RULE / ON-DEVICE ML / ON-DEVICE AI · ESTIMATE / YOUR HISTORY）が出る。Apple Intelligence をオフにしたエラーのヒントは RULE
- [ ] Archive で「昨日のフランス語の看板は何？」と入力して Return → 記録を根拠にした答えと引用が出る。記録に無いことを聞くと「記録がない」と答え、作り話をしない
- [ ] 丸で囲んで出たカードを繰り返すと、その種類のカードが出やすくなる（Personalization）

**辞書・要約・開発ルール・マイナンバー（v0.11）**
- [ ] Apple Intelligence をオフにして専門用語を丸で囲むと、macOS の辞書の意味が `SRC ▸ DICTIONARY` で出る（サンドボックス内で Dictionary Services が使えること）
- [ ] ⌥⌘S で 3 行の要約が出て、Archive に SUMMARY として残る。⌥⌘K と ⌥⌘S がそれぞれ正しい動作をする（ホットキーの取り違えがない）
- [ ] 文章の少ない画面で ⌥⌘S → 「要約するほどの文章がありません」が短く出る
- [ ] Python / Node のエラーで、カードに `⌖ 自分のコード: …` が出る（ライブラリの行ではない）
- [ ] crontab の行にポインタを置くと「5分ごと」などが出る
- [ ] 画面共有中にマイナンバー（4-4-4 区切り）を表示すると警告が出る。注文番号などの 12 桁では出ない
