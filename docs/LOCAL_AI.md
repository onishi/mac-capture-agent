# ローカル AI 設計とアイデア集

要件は [SPEC.md](SPEC.md)、構成は [ARCHITECTURE.md](ARCHITECTURE.md)、順序は [ROADMAP.md](ROADMAP.md)（M6）。
本書は「クラウド LLM を使わず、Mac の中だけで何ができるか」を整理し、ローカル AI の設計方針とアイデアの一覧（要件 ID `LA-*`）を定める。

---

## 1. 方針（ROADMAP D-7、2026-10 決定）

| # | 方針 |
| --- | --- |
| 1 | **クラウド LLM は使わない。** Gemini を含む外部 AI API への送信をやめ、ネットワーク Entitlement も外す。アプリは通信しない（WEB / WIKI はブラウザで開くだけ） |
| 2 | **精度より「ローカルで完結すること」を優先する。** 精度が低いことは許容し、代わりに「推定」であることを必ず表示する |
| 3 | 表示しないことを優先する原則（P-1）は変えない。精度が低いぶん、出す条件は厳しくする（画面上の文字で裏付けが取れたときだけ断定、それ以外は「〜かもしれません」） |
| 4 | 3 段構えで、上の段が使えない環境でも下の段だけで何かを返す（§2） |
| 5 | LLM の出力は値型に受けてから Core のサニタイザで検査する（長さ・言語・定型の言い訳・入力の繰り返しを除外） |
| 6 | 人物は「画面に名前が書かれている公人」だけ。顔から人を特定しない（ID-5 は引き続き実装しない） |

## 2. ローカル AI の 3 段構成

| 段 | 中身 | 動く環境 | 用途の例 |
| --- | --- | --- | --- |
| L0 ルール・辞書 | `AmbientCore` の純粋関数（正規表現・表・チェックサム・単位換算） | すべて（Linux でテスト可） | 単位換算、エラーのヒント、略語の定義の拾い出し、秘密情報 |
| L1 Apple のオンデバイス ML | Vision（OCR・画像分類・顔の有無・バーコード）、NaturalLanguage（言語判定・固有名詞・埋め込み）、Translation、`NSDataDetector`、辞書（Dictionary Services） | macOS 15 以上 | 翻訳、画像の粗分類ラベル、日付、固有名詞 |
| L2 オンデバイス LLM | Foundation Models（`SystemLanguageModel`、テキストのみ、`@Generable` で構造化出力） | macOS 26 + Apple Intelligence | 説明・要約・判定・世界知識による推定 |

- L2 は画像を直接見られない（2026-10 時点の前提）。画像は L1 の分類ラベル＋画面上の文字に変換してから L2 に渡す。**画像の識別精度は低い**（ラベルが「鳥」程度なら「鳥」としか言えない）。
- L2 の世界知識は学習時点まで。ニュースの「最新の経緯」は分からないので、一般的な背景だけを出し、経緯は Archive（自分が読んだ記事）から作る。
- 将来の L3（判断事項 D-8）: Core ML / MLX のローカル VLM・汎用 LLM。モデルの配布サイズと外部依存が大きいため、現時点では入れない。

### 2.1 推定の表示ルール

| 状況 | 表示 |
| --- | --- |
| L0 / L1 の決定的な結果（単位換算・QR・日付） | そのまま |
| L2 の世界知識による推定で、名前が画面上の文字にも出ている | 名前はそのまま、出典欄に `ON-DEVICE` |
| L2 の推定で画面上の裏付けがない | 「〜かもしれません」/「(possibly)」を付ける |
| L2 が「分からない」と答えた、またはサニタイザで落ちた | 何も出さない |
| 画像分類ラベルの確度が 0.3 未満 | L2 に渡さない |

### 2.2 呼び出し予算

- L2 の呼び出しはパイプライン全体で 8 秒に 1 回まで（既存の `llmLimiter`）。識別は 20 秒に 1 回まで。
- Battery モードでは L2 を「ユーザー操作起点（ポインタ滞在・Archive の質問）」だけにする（将来）。
- 結果は `knowledge` テーブルに `source = "on-device"` でキャッシュ（見送りもキャッシュ）。

## 3. 旧クラウド機能の置き換え

| 旧（Gemini） | 新（ローカル） | 精度の見込み | ID |
| --- | --- | --- | --- |
| 切り抜き画像 → 動植物・ランドマーク・料理・製品の識別 | Vision の分類ラベル（上位の具体的なもの）＋周辺の文字 → Foundation Models が名前と補足 3 つ | 低〜中。キャプションに名前があれば高い | LA-1 |
| 人名＋周辺テキスト → 公人の判定 | 同じ入力を Foundation Models の知識で判定。画面上の名前と一致しないと出さない | 中（有名人のみ） | LA-2 |
| ウィンドウタイトル → 作品カード（Google 検索なし） | Foundation Models の知識。有名作のみ、確信がなければ出さない | 中（新作は不可） | LA-3 |
| 見出し → 背景・経緯（Google 検索連携） | 見出しの固有名詞の一般的な背景（Foundation Models）＋ Archive の関連記事を時系列に | 背景は中、経緯は自分の閲覧履歴の範囲のみ | LA-4 |
