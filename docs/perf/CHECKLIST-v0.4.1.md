# 実機検証チェックリスト（v0.4.1）

ROADMAP M0 の完了条件。結果欄に ✅ / ❌ / ⚠（既知の制限として記載）とメモを記入し、❌ は再現手順を Issue かこのファイルに残す。

## 準備

1. Xcode で Team を設定してビルド（⌘R）。
2. 設定（メニュー › Settings…）› Developer › **Debug overlay** をオン。
   - 画面左上に `◢ DEBUG // PIPELINE` パネルが出る。
   - 色: 変化領域＝マゼンタ点線、OCR 範囲＝黄、表示した候補＝緑、見送った候補＝赤（ラベルに種類とスコア、`COOLDOWN`）。
   - 認識したテキストは表示されない（スコア・件数・時間のみ）。
3. Console.app でサブシステム `com.onishi.AmbientScreenIntelligence` を表示しておく。
4. Instruments を使う場合は「Points of Interest」で `ocr` / `translate` の区間が見える。
