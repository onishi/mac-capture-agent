## 1. 今できること

### 1.1 基本の動き

| 動き | 内容 |
| --- | --- |
| 常に見ている | 画面の**変化した部分だけ**を読み取る（OCR）。動画など変わり続ける部分は止まったときに 1 回だけ |
| 黙っている | 既定は「何も出さない」。価値がありそうなときだけ HUD を数秒出す。同じものは 5 分出さない |
| 学ぶ | ✕・NOT USEFUL で減らし、ホバー・コピー・検索で増やす（アクション × 言語 × アプリの重みだけ。文章は学習に使わない） |
| 覚える | HUD に出したもの、読んだページのタイトル・URL・閲覧時間を記録。⌥⌘K の Archive で「昨日のフランス語」のように検索 |
| 守る | パスワード管理・メッセージ・写真などは画像から除去して解析しない。画面画像は保存しない |

### 1.2 自動で出るもの

「AI なし」は Apple Intelligence が無い Mac（macOS 15 など）でも動くもの。

| 場面 | HUD | AI なし | 備考 |
| --- | --- | --- | --- |
| 外国語の文章 | 翻訳＋（AI あり）ひとことメモ | ✅ | Apple の翻訳モデルを事前にダウンロード |
| 知らない専門用語 | 1〜2 行の解説 | 🟡 | AI なしでは「以前に画面で定義された略語」の展開か、macOS の辞書の意味 |
| ターミナルのエラー | 原因候補と次の一手、スタックトレースの「自分のコード」の行 | ✅ | AI なしでは代表的な 25 種類のルールのヒント |
| QR コード | 行き先の URL | ✅ | |
| 画面共有中の API キー等 | 警告（実験: 黒塗り） | ✅ | 値は保存も表示もしない |
| 動物・植物・料理・製品・建物の写真 | 名前と補足 3 つ（推定） | ❌ | 画像は LLM に渡らず、分類ラベルと周辺の文字から推定。外れやすい |
| 顔＋字幕の人名 | 公人なら肩書きと代表作（推定） | ❌ | 顔から人を特定しない |
| 配信サイトで動画を見始めた | 作品カード（年・原作・キャスト・主題歌） | ❌ | 有名作のみ。ネタバレ 0〜3 段階 |
| 字幕にキャラクター名 | 演者名 | ❌ | 作品カードのキャストと照合 |
| ニュース記事を開いた | 一般的な背景＋以前に読んだ関連記事 | 🟡 | 最近の出来事は分からない。AI なしでは関連記事だけ |
| 4 時間以上空いて戻った | 「前回の続き」 | ✅ | ブックマークと主なページ |

### 1.4 できないこと（現時点）

- 画像そのものを理解すること（端末内の LLM はテキストしか読めない。D-8 で検討中）
- 最近のニュース・新しい作品の情報（LLM の知識は学習時点まで、Web 検索もしない）
- 起動時点ですでに表示されている内容の解析（変化した部分だけが対象）
- 丸以外のジェスチャ（下線・✕・✓ など、§2.1）
- 音声・マイク

## 2. これからのアイデア

### 2.1 丸で囲んで調べる（能動的な調査）— LA-60 は v0.11 で実装済み

**状態**: ⌥ を押しながら丸で囲む操作（案 A）を実装済み（CI 済み、実機未確認）。案 B・C と「さらに広げる案」（LA-61）は未着手。以下は設計の記録。追加の権限は要らない見込み（実機で要確認）。

実装: `Sources/AmbientCore/Interaction/CircleGesture.swift`（判定）、`ActiveLookup.swift`（何を出すか）、`Sources/AmbientApp/Interaction/CircleGestureMonitor.swift`（ポーリング）、`GestureTrailController.swift`（軌跡）、`AnalysisPipeline.lookUp(region:)`。設定の「⌥ を押しながら丸で囲んだものを調べる」でオフにできる。

| 必要なもの | 現状 | 見込み |
| --- | --- | --- |
| ポインタの軌跡 | ポインタ位置はすでに `CGEvent(source: nil).location` で読んでいる（権限不要） | 30〜60 Hz で読むだけ。CPU 負荷は小さい |
| 修飾キーの状態 | 未使用 | `CGEventSource.flagsState(.combinedSessionState)` で読める見込み。入力監視の権限が要らないことを実機で確認する |
| 囲んだ範囲の画像 | `FrameBuffer.currentFrame` に最新フレームがメモリ上にある | 変化の有無に関係なく、その範囲を OCR・分類・QR 検出できる |
| HUD | 既存 | 軌跡を描き、閉じたら `TARGET LOCK` の演出 |

**操作の案**

| 案 | 内容 | 誤検出 | 推奨 |
| --- | --- | --- | --- |
| A | **⌥（Option）を押しながら**ポインタで丸を描く | ほぼ無い | ◎ 既定 |
| B | 修飾キーなしで、素早く 1 周の丸を描く | 普段の操作で誤検出しうる | 設定でオン |
| C | ホットキー（例 ⌥⌘L）→ 範囲をドラッグ | 無い | 丸が描きにくい人向け |

**丸の判定（Core の純粋関数 `CircleGestureRecognizer`、テスト可能）**

- 入力: 時刻つきのポインタ座標の列（画面に対する正規化座標）
- 条件: 0.3〜3 秒で描かれた／始点と終点の距離が直径の 30% 以内／進行方向の回転の合計が 300° 以上／半径のばらつき（標準偏差 ÷ 平均）が 0.35 以下／大きさが画面の 2〜60%
- 出力: 囲んだ範囲の矩形（少し余白を足す）

**囲んだ後の流れ**

1. 範囲を最新フレームから解析（OCR・画像分類・QR・秘密情報の検出）。除外アプリ・秘密情報の扱いは通常と同じ。
2. **ignore-first とクールダウンを外す**（ユーザーが明示的に頼んだため）。中身に応じて一番合うものを出す:
   QR → エラー → 外国語（翻訳）→ 専門用語 → 単位 → コード → 写真（識別の推定）→ それ以外は LLM の「これは何？」（1〜2 行の要約）
3. 何も分からなかったときは、P-7（失敗は見せない）の例外として小さく `NO INTEL` を 1 秒だけ出す（頼まれたのに無反応だと壊れたように見えるため）。
4. 「丸で囲んだ」は最も強い関心として Personalization に +3（v0.11 で実装）。

**さらに広げる案**

| ジェスチャ（⌥ を押しながら） | 動作 |
| --- | --- |
| 丸で囲む | 調べる（上記） |
| 下線を引く | その行だけ翻訳（言語判定のしきい値を無視） |
| 2 重丸 | 詳しく（長めの説明、Archive に保存） |
| ✕ を描く | 表示中の HUD を閉じて今後出さない（NOT USEFUL） |
| ✓ を描く | ブックマーク |
| 矩形でなぞる | 範囲の文章を要約 |

将来の音声（FU-3「これ誰？」）とも同じ「範囲 → 調べる」の経路を共有できる。

**実装の分け方（案）**

| 段階 | 内容 | 規模 |
| --- | --- | --- |
| 1 | Core: `CircleGestureRecognizer` とテスト（実際の軌跡の例をテストデータに） | S |
| 2 | App: ⌥ が押されている間だけ 60 Hz でポインタを読み、軌跡を HUD に描く | S |
| 3 | App: 囲んだ範囲の解析と「一番合うもの」の選択（Core の純粋関数で優先順位を決める） | M |
| 4 | 実機: 修飾キーの読み取りに権限が要らないこと、誤検出、応答時間（目標 1 秒以内に最初の表示） | S |
